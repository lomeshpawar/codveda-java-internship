# Codveda Java Internship Projects

A structured collection of Java projects completed as part of the **Codveda Java Internship**, progressing from core Java fundamentals to object-oriented programming, JDBC/database integration, and multithreaded networking.

## 📌 Project Overview

| Level | Project | Key Concepts |
|---|---|---|
| Level 1 | [Basic Calculator](Level-1/Basic-Calculator/) | Java fundamentals, input handling, arithmetic operations |
| Level 1 | [Number Guessing Game](Level-1/Number-Guessing-Game/) | Random numbers, loops, conditions, user input |
| Level 2 | [Employee Management System](Level-2/Employee-Management-System/) | OOP, collections, CRUD operations |
| Level 2 | [Banking Application](Level-2/Banking-Application/) | OOP, encapsulation, transactions, validation |
| Level 3 | [Library Management JDBC](Level-3/Library-Management-JDBC/) | JDBC, MySQL, SQL, database operations |
| Level 3 | [Multithreaded Chat](Level-3/Multithreaded-Chat/) | Sockets, client-server architecture, multithreading |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/lomeshpawar/codveda-java-internship.git
cd codveda-java-internship
```

### 2. Open a project

Navigate to the required project's `src` directory and compile the Java source files with JDK 17 or later.

Example:

```bash
cd Level-1/Basic-Calculator/src
javac BasicCalculator.java
java BasicCalculator
```

Each project contains its own README with project-specific details and instructions.

## 🗃️ Level 3 Database Setup

The **Library Management JDBC** project requires MySQL. Configure the database credentials and connection settings according to the project's README before running it.

> Never commit passwords, API keys, database credentials, or other secrets to GitHub.
