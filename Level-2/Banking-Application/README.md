# Banking Application

## Features
- Create account
- Deposit money
- Withdraw money
- Check balance
- View account details
- Insufficient-balance validation

## Concepts
- OOP
- Encapsulation
- HashMap
- Input validation
- Methods and control flow

## Run
```bash
javac src/*.java
java -cp src BankingApplication
```

This is an educational console application, not a production banking system.
